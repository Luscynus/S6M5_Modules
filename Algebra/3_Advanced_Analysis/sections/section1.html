Section 1: Tangents to Non-Polynomial Functions

Geometric Foundations & Local Linearity

When working with exponential, logarithmic, and trigonometric curves, finding a tangent line uses the exact same ideas we used for basic polynomial curves. Even though these graphs bend and twist through space, if you zoom in close enough to any smooth point on the curve, the graph begins to look like a straight line. This property is called local linearity, and it means that the curve matches the straight tangent line at that exact spot.

Core Definition: The Point-Slope Tangent Formula

To find the equation of a straight tangent line that touches a curve y = f(x) at a specific point where x = c, we use the standard point-slope formula. We just need to find the exact y-coordinate f(c) and the exact derivative slope f'(c) at that point, then plug them directly into the line formula:

y - f(c) = f'(c) \cdot (x - c)

Here is what each part of this formula means when writing out your math steps:

  • c — The specific x-value given in the problem where the line touches the curve.
  • f(c) — The y-coordinate of the point, found by substituting c into the original function.
  • f'(c) — The exact slope of the tangent line, found by substituting c into the derivative function.

Continuous Limits & The Radian Constraint

Before calculating rates of change for trigonometric functions, we have to look at how angles are measured. In basic geometry, we use degrees to measure rotations. However, in calculus, the mathematical laws that prove derivatives only work if angles are measured in Radians.

The Calculus Trigonometric Derivative Axioms

When an angle x is measured continuously in radians, the fundamental trigonometric limit laws allow us to establish clean derivative matching formulas. If you differentiate a sine wave, it turns into a cosine wave. If you differentiate a cosine wave, it introduces a negative sign:

ddx [sin(x)] = cos(x)
ddx [cos(x)] = -sin(x)
The Angle Measurement Mistake Warning

Critical Trap: When evaluating trigonometric values like sin(c) or derivative slopes like -sin(c) in calculus, your calculator must always be set to Radian Mode.

Using degree values (like plugging in 90 degrees instead of pi/2) completely breaks the underlying calculus limits. This is a very common student mistake that changes your numerical tangent slopes entirely and leads to incorrect final line equations.

Worked Example: Tangent Line to an Exponential Function

Find the equation of the tangent line to the exponential function f(x) = (2x - 3) · ex at the point where x = 0.

Solution Steps:
  1. Find the y-coordinate of the point

    We substitute our given point c = 0 directly into the function to calculate the corresponding y-value:

    f(0) = (2(0) - 3) · e0 = (-3) · 1 = -3

    This gives us the point on the graph at the coordinates (0, -3).

  2. Differentiate and calculate the slope of the tangent line

    We use the Product Rule to find the general derivative function f'(x):

    f'(x) = (2) · ex + (2x - 3) · ex = ex · [2 + 2x - 3] = ex · (2x - 1)

    We substitute c = 0 into the derivative to find the exact slope at that point:

    f'(0) = e0 · (2(0) - 1) = 1 · (-1) = -1
  3. Simplify the equation into standard form

    We substitute our calculated values into the tangent line formula and solve for y:

    y - (-3) = -1 · (x - 0) ⇒ y + 3 = -x ⇒ y = -x - 3
Worked Example: Tangent Line to a Trigonometric Function

Find the equation of the tangent line to the function g(x) = 3cos(x) at the point where x = π2.

Solution Steps:
  1. Find the y-coordinate of the point

    We evaluate the function directly at our given radian value:

    g(π2) = 3cos(π2) = 3 · 0 = 0

    This means the point lies exactly on the x-axis at the coordinates (π2, 0).

  2. Differentiate and calculate the slope

    We use our standard trigonometric derivative rule to find the derivative function and evaluate it at our point to find the slope:

    g'(x) = -3sin(x) ⇒ g'(π2) = -3sin(π2) = -3 · 1 = -3
  3. Write down the final line equation

    We substitute our values into the formula to complete the calculation:

    y - 0 = -3 · (x - π2) ⇒ y = -3x + 3π2
