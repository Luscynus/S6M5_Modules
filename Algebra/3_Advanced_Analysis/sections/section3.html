3. Optimisation with Non-Polynomial Functions

Optimisation with Non-Polynomial Functions

We are extending our study of optimization by applying calculus rules to exponential and logarithmic curves. When finding where a non-polynomial function reaches its peak maximum value or lowest minimum value, we use the exact same foundational method as before: we calculate the derivative function and isolate its stationary turning points where the slope equals zero.

Core Methodology: Isolating Turning Points

To calculate the precise location of local extrema on a non-polynomial curve, we set our simplified derivative to zero and solve for the valid input coordinates:

f'(x) = 0

When working with combinations of exponential terms, this optimization step becomes much simpler by applying a critical algebraic property:

  • An exponential expression is strictly greater than zero for all real numbers (ex > 0).
  • Because it can never equal zero (ex ≠ 0), you can safely divide both sides of your optimization equation by the exponential term to isolate the remaining algebraic expression.
The Logarithm Domain Trap — Check Candidates Immediately

When solving optimization equations that include natural logarithms (ln(x)), any stationary point candidate you find by setting the derivative to zero must be cross-checked against the basic logarithmic domain restriction:

x > 0

Because logarithms are undefined for negative numbers or zero, any calculated turning point value that is negative or equal to zero is physically impossible and must be rejected immediately from your solution set!

2. Step-by-Step Optimization Solutions

Review these step-by-step solutions to see how we apply the Product and Quotient rules to locate and verify the exact peak or lowest points on non-polynomial curves.

Example 3.1. A function representing the efficiency of a system is given by the formula:
f(x) = x2 · e−x    for all x > 0
Find the exact coordinates of the point where the function reaches its absolute maximum value.
Solution Steps:
  1. Differentiate the Function using the Product and Chain Rules:

    We separate our function into its two factors and apply the Product Rule, keeping in mind that the derivative of e−x is −e−x:

    f'(x) = (2x) · e−x + x2 · (−e−x)

    Next, we simplify the expression by taking out the common exponential term as a factor:

    f'(x) = e−x · (2x − x2) = x · e−x · (2 − x)
  2. Find the Stationary Points by Setting the Derivative to Zero:

    To find our turning point candidates, we set the factored derivative formula equal to zero:

    x · e−x · (2 − x) = 0

    We check each isolated multiplier component separately to find our valid solutions:

    • x = 0 ⇒ This is the starting edge boundary of our open domain.
    • e−x = 0 ⇒ No solution exists, because an exponential term is strictly positive (e−x > 0).
    • 2 − x = 0 ⇒ x = 2
  3. Calculate the Matching Peak Y-Coordinate:

    We substitute our verified stationary point back into the original curve function to find the exact peak height output:

    f(2) = (2)2 · e−2 = 4e2

    The system stability analysis confirms that the absolute maximum efficiency value occurs exactly at the coordinates: (2, 4e2).

Example 3.2. A logarithmic curve is defined by the fractional formula:
g(x) = xln(x)    for all x > 1
Find the exact value of x where the function reaches its absolute minimum turning point.
Solution Steps:
  1. Calculate the Derivative using the Quotient Rule:

    We Differentiate our top and bottom functions using the fraction rule, squaring the denominator base:

    g'(x) = (1) · ln(x) − x · (1x)(ln(x))2 = ln(x) − 1(ln(x))2
  2. Isolate the Turning Point Candidate by Setting the Derivative to Zero:

    A fraction can only equal zero when its numerator is zero, so we solve for the upper expression:

    ln(x) − 1 = 0 ⇒ ln(x) = 1

    To eliminate the natural logarithm, we rewrite both sides using base e as an exponent:

    eln(x) = e1 ⇒ x = e

    The system verification records confirm that the absolute minimum value occurs exactly at the point where x = e.
