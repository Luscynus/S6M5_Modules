2. Asymptotes of Non-Polynomial Functions

Asymptotes of Non-Polynomial Functions

We are continuing our study of graphs by looking at fractions that combine exponential, logarithmic, and trigonometric functions. When these different types of functions are mixed together, finding the domain breaks and the behavior of the graph at the far horizons requires combining basic limit rules with our Growth Hierarchy.

Core Rules: Finding Vertical and Horizontal Asymptotes

Finding the vertical and horizontal asymptotes of a non-polynomial fraction follows the exact same basic rules used for rational functions, checked in two different ways:

  • Vertical Asymptotes (VA): Found at values where the denominator is equal to zero, causing the function values to grow to infinity.
    x = c ⇒ limit as x approaches c from the left or right of f(x) = ±∞
  • Horizontal Asymptotes (HA): Found by calculating what happens to the graph at the far ends as x goes to infinity, approaching a single fixed number.
    y = L ⇒ limit as x approaches ±∞ of f(x) = L
The Exponential Difference — Always Check Both Ends Separately

Unlike polynomial fractions which have the same behavior at both ends of the graph, exponential functions work completely differently on the left and right sides. Because of the fundamental limits:

limit as x approaches +∞ of e^x = +∞   and   limit as x approaches -∞ of e^x = 0

An exponential fraction can have completely different horizontal asymptotes on the left and right horizons. Forgetting to calculate both directions separately will cause you to miss entire boundary lines!

Step-by-Step Proof Coordinates

Review these step-by-step solutions to see how we apply limit operations on both horizons and analyze domain breaks to find non-polynomial asymptote lines.

Example 2.1. Find all the horizontal and vertical asymptotes for the given exponential function:
f(x) = 4ex + 2
Solution Steps:
  1. Scan for Vertical Asymptotes via Denominator Zeros:

    We check for values of x that make the denominator equal to zero:

    ex + 2 = 0 ⇒ ex = -2

    Because an exponential expression is always positive (ex > 0 for all real numbers), this equation has no real solutions. The denominator can never equal zero, meaning the function has no domain breaks and no Vertical Asymptotes (VA) exist.

  2. Evaluate the Horizontal Boundary at Positive Infinity:

    We check what happens to the graph on the far right side as x goes to infinity (x approaches +∞):

    limx ⇒ +∞ 4ex + 2 = 4+∞ + 2 = 0

    This shows that the horizontal line y = 0 (the x-axis) is a Horizontal Asymptote (HA) as x approaches +∞.

  3. Evaluate the Horizontal Boundary at Negative Infinity:

    We check what happens to the graph on the far left side as x goes to negative infinity (x approaches -∞), using the rule that the limit as x approaches -∞ of ex = 0:

    limx ⇒ -∞ 4ex + 2 = 40 + 2 = 2

    This shows that a second horizontal line y = 2 is a Horizontal Asymptote (HA) as x approaches -∞.

Example 2.2. Find the equations of all the asymptotes for the given logarithmic fraction:
g(x) = 2x - 6ln(x)    for x > 0, x ≠ 1
Solution Steps:
  1. Evaluate Domain Discontinuities for Vertical Asymptotes:

    The natural logarithm requires x to be strictly greater than zero (x > 0). Since it is in the denominator, we also cannot have ln(x) = 0, which gives the restriction x = 1. We find the one-sided limits as x approaches this break from the left and right sides:

    limx ⇒ 1− 2x − 6ln(x) = −40− = +∞
    limx ⇒ 1+ 2x − 6ln(x) = −40+ = −∞

    ↳ Critical Step Visualisation: When x approaches 1 from the left side (like 0.99), the value of ln(x) is slightly negative (0−). Dividing a negative numerator (−4) by a negative denominator (0−) creates a positive output trend (+∞). When x approaches 1 from the right side (like 1.01), ln(x) becomes slightly positive (0+), keeping the final division trend negative (−∞).

  2. Evaluate Limits at Infinity using Growth Dominance Hierarchy:

    We check what happens to the fraction on the far right end as x approaches +∞. According to our Growth Hierarchy, a polynomial function grows much faster than a logarithmic function (ln(x) « x). Because the numerator grows much faster than the denominator, the entire fraction grows larger and larger without bound:

    limx ⇒ +∞ 2x - 6ln(x) = +∞

    Since the values do not approach a single fixed number, no Horizontal Asymptotes (HA) exist.
