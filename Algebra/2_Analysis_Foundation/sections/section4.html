4. Introduction to Limits & Continuity

The Limit of a Function

A limit tracks the output trajectory of a function as its input value approaches a specific point c. It isolates behavior nearby without caring about the value at the exact spot:

limx → c f(x) = L
Linear Limit Distribution Laws:

Provided limits exist independently, they distribute freely across standard arithmetic functions:

  • Sum Rule: lim [f(x) + g(x)] = lim f(x) + lim g(x)
  • Product Rule: lim [f(x) · g(x)] = lim f(x) · lim g(x)
  • Quotient Rule: lim [f(x)g(x)] = lim f(x)lim g(x)   (provided lim g(x) ≠ 0)
The 4 Algebraic Indeterminate Forms:

Direct substitution frequently yields values that are mathematically undefined. These are indeterminate forms. They do not mean the limit doesn't exist, but rather that more structural work must be done to evaluate them:

  • Cancellation Form (0 ⁄ 0): Indicates a removable hole. Resolved by factoring or rationalization.
  • Infinite Ratio (∞ ⁄ ∞): Arises when evaluating behaviors at infinity. Resolved by dividing by the highest denominator power.
  • Zero-Infinity Product (0 · ∞): Occurs when competing elements try to simultaneously ground out and explode. Resolved by rewriting as a fraction.
  • Infinite Difference (∞ − ∞): Occurs when subtraction involves opposing values of indeterminate sizes. Resolved by finding common denominators.

One-Sided Paths & Piecewise Continuity

Piecewise functions shift formulas across specific boundary conditions. To trace these connections accurately, we evaluate independent directional limits:

  • Left-Hand Path (x → c−): Limits computed utilizing values arriving from the lower left (x < c).
  • Right-Hand Path (x → c+): Limits computed utilizing values arriving from the upper right (x > c).
⚙️ Formal Continuity Verification Protocol:

A piecewise boundary achieves perfect geometric continuity if and only if it fulfills three conditions simultaneously:

1. f(c) exists
2. limx→c f(x) exists
3. limx→c f(x) = f(c)

Example 4.1 (Indeterminate Form Elimination): Evaluate the rational fraction limit:
lim x³ − 2x² − x + 2x² − 4
Solution Steps:
  1. Direct Substitution: Plugging in x = 2 gives 00. This indeterminate form alerts us to a hidden common factor hole.
  2. Factorization Steps:
    ↳ Numerator via grouping: x²(x−2) − 1(x−2) = (x−2)(x²−1) (Factor Theorem Remainder from section 3 also works)
    ↳ Denominator via difference of squares: (x−2)(x+2)
  3. Cancel and Evaluate: Cancel out the zero-inducing binomial component (x−2) safely:
    lim x² − 1x + 2 = (2)² − 12 + 2 = 34
Example 4.2 (Piecewise Continuity Verification): A function is defined across a boundary interface by:
f(x) =
{
3x − 1 if x < 1
k · x² if x ≥ 1

Find the constant parameter k that hooks up both paths continuously at x = 1.

Solution Steps:
  1. Left-Hand Path: lim (3x − 1) as x → 1− yields 3(1) − 1 = 2
  2. Right-Hand Path: lim (k · x²) as x → 1+ yields k(1)² = k
  3. Enforce Matching Law: Set left limit equal to right limit to bridge the functional gap: 2 = k ⇒ k = 2.
