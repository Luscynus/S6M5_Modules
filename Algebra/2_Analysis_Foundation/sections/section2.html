2. Composite & Inverse Functions

Function Composition: Chains of Operations

Imagine passing a number into a machine, taking the output it spits out, and dropping it directly into a second machine. This pipeline is called Function Composition.

The Composite Notation:

Given two functions, f and g, the combined operation is written as:

(f ○ g)(x) = f(g(x))

Order Matters: You always evaluate from the inside out! Work out g(x) first, then substitute that entire algebraic result into f.

🚨 Domain Warning Constraint:

For f(g(x)) to exist, the input x must be valid for g(x), AND the output value coming out of g(x) must sit cleanly inside the domain boundaries of the outer function f.

Inverse Functions: Reversing the Machine

An Inverse Function acts as an undo operation. If the original function maps an input x to a height y, the inverse function takes that height y and tracks it back to the original starting input x.

Core Identity Conditions:
  • The inverse function notation is written as: f−1(x)
  • Applying them back-to-back cancels out the algebra: f(f−1(x)) = x and f−1(f(x)) = x
  • Domain & Range Flip: The domain of the inverse matches the range of the original, and vice versa.
    D(f−1) = R(f)   &   R(f−1) = D(f)
The 3-Step Algebraic Procedure to find f−1(x):
  1. Set the function expression equal to y ⟶ y = f(x)
  2. Rearrange and solve the entire equation strictly to isolate variable x.
  3. Swap your variable letters (x and y) to present the final formula.

Demonstration Masterclass

Example 2.1 (Composition): Given f(x) = x² + 3 and g(x) = 2x − 1, evaluate f(g(x)).
Solution Steps:
  1. Target the outer function frame: f([ ]) = [ ]² + 3
  2. Drop the entire expression for g(x) into the slot:
    f(g(x)) = (2x − 1)² + 3
  3. Expand the binomial identity square and collect numeric constants:
    f(g(x)) = (4x² − 4x + 1) + 3
    f(g(x)) = 4x² − 4x + 4
Example 2.2 (Finding an Inverse): Find the inverse formula for the fractional function f(x) = 2x + 1x − 3.
Solution Steps:
  1. Set expression equal to y and cross-multiply the denominator boundary:
    y = 2x + 1x − 3 ⟶ y(x − 3) = 2x + 1
    xy − 3y = 2x + 1
  2. Gather all terms with variable x on one side, and factor it out cleanly:
    xy − 2x = 3y + 1
    x(y − 2) = 3y + 1
  3. Divide across to isolate x, then swap variables for the terminal inverse answer:
    x = 3y + 1y − 2 ⟶ f -1(x) = 3x + 1x − 2
