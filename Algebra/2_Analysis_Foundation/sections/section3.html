3. Symmetry, Parity & Polynomials

Function Parity: Even vs. Odd Symmetry

Parity describes how a function reacts when you flip the sign of its input variable. Testing this algebraically reveals core geometric symmetries instantly.

🚀 ADVANCED CALCULUS PREVIEW: WHY THIS MATTERS

Mastering parity unlocks algebraic shortcuts down the road! For example, when calculating the area under a curve or volumes of solid rotations in integral calculus:

  • Knowing that a function like cos(x) is strictly Even means integrating symmetric boundaries collapses into a simple shortcut: Total Area = Single Area × 2.
  • Conversely, integrating an Odd function over symmetric intervals instantly equals 0 because the positive and negative halves cancel each other out completely without needing a single calculation!
📐 COMPARISON MATRIX: Y-AXIS VS. ORIGIN SYMMETRY
💡 Notice how the Even blue line mirrors across the Y-axis, while the Odd pink line rotates 180° through the central origin dot (0,0).
The Algebraic Rules Matrix:
  • Even Functions (Reflectional): Substituting −x preserves the exact original formula expression.
    f(–x) = f(x)
  • Odd Functions (Rotational): Substituting −x negates the entire absolute formula output.
    f(–x) = –f(x)

Finding Obvious Roots & Synthetic Division

To factor higher-degree polynomials quickly without relying on long division, we can screen for an obvious root using three specific coefficient rules for x ∈ {0, 1, −1}:

🎯 The 3 Rules for Obvious Roots:
  • Rule 1: If x = 0 is a root ⟶ The polynomial has no constant number at the absolute end, meaning you can factor out x immediately.
  • Rule 2: If x = 1 is a root ⟶ The sum of all coefficients across the entire polynomial equals exactly zero (∑ Coefficients = 0).
  • Rule 3: If x = −1 is a root ⟶ The sum of the coefficients of the even powers equals the sum of the coefficients of the odd powers.
💡 What if these shortcuts don't apply? You can always check any suspect number by directly substituting it into the polynomial expression. If evaluating the formula outputs exactly 0, you have successfully found a root! For example: P(c) = 0 ⇔ x = c is a root.
The Factor Theorem Remainder Hook:

Once an obvious root value c is discovered, it guarantees that (x − c) divides perfectly into the polynomial, dropping your remaining expression's degree by one level through a quick synthetic division setup grid.

⚙️ SYNTHETIC DIVISION ALGORITHMIC BLUEPRINT
🎯 1. Bring the leading coefficient down directly.
🔄 2. Multiply that value by root c and slide the result up into the next column.
➕ 3. Add the vertical column numbers together, then repeat the loop across the line.

Demonstration Masterclass

Example 3.1 (Parity): Prove algebraically whether f(x) = 3x⁴ − x² + 7 is Even, Odd, or Neither.
Solution Steps:
  1. Substitute negative parameter: Replace every instance of x with an enclosed negative parameter (−x):
    f(−x) = 3(−x)⁴ − (−x)² + 7
  2. Evaluate the powers: Since both exponents are even numbers, signs return positive:
    f(−x) = 3x⁴ − x² + 7 = f(x)  ⟶  Strictly Even.
Example 3.2 (Full Cubic Factoring): Factor the cubic polynomial completely:
P(x) = 2x³ − 4x² − 2x + 4
Solution Steps:
  1. Step 1: Check for an obvious root

    Add up the absolute values of all coefficients:

    ∑ Coefficients = 2 + (−4) + (−2) + 4 = 2 − 4 − 2 + 4 = 0

    Because the sum equals zero, x = 1 is our first root, which means (x − 1) is our first linear factor.

  2. Step 2: Use synthetic division to reduce the polynomial degree

    Drop your root indicator 1 on the left side and perform the algorithmic step loops:

    The bottom row coefficients generate our quadratic quotient expression:

    P(x) = (x − 1)(2x² − 2x − 4)
  3. Step 3: Solve the remaining quadratic segment

    Factor out the leading constant factor 2 and break down the remaining trinomial array:

    2x² − 2x − 4 = 2(x² − x − 2) = 2(x − 2)(x + 1)

    Combine all pieces together to state your final, completely factored polynomial formula:

    P(x) = 2(x − 1)(x − 2)(x + 1)
