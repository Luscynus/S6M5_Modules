10. Curve Sketching and Asymptotes

The 4 Steps to Analysing a Curve

To sketch the complete graph of an unknown function systematically without a calculator, we follow an intentional four-stage mathematical breakdown. This shifts our focus away from long, point-by-point guessing tables and isolates the exact landmarks and boundary lines that govern coordinate behavior.

Standard Curve Analysis Protocol

Execute these four analytical phases sequentially to map out the complete geometric blueprint of any continuous function architecture:

STAGE 01: Find the Domain Restrictions

Isolate structural breaks in the curve. Before graphing, you must map where the function is legally allowed to exist by scanning for three core algebraic domain restrictions:

A: Denominators
1g(x) ⇒ g(x) ≠ 0

The denominator cannot equal zero. This pinpoints a vertical asymptote break line.

B: Square Roots
√g(x) ⇒ g(x) ≥ 0

Inside terms must be non-negative. This excludes values that lead to imaginary numbers.

C: Logarithms
ln(g(x)) ⇒ g(x) > 0

Arguments must be strictly greater than zero. This creates an open domain boundary line.

STAGE 02: Locate Axis Intercepts

Pin down where the curve crosses the axes on your coordinate system. These intersection points act as explicit anchors holding your curve outline onto the grid layout:

  • x-Intercepts (Roots): Set the total output equation equal to zero: f(x) = 0. This tells you exactly where the path crosses the horizontal axis line.
  • y-Intercept (Initial Gate): Substitute input parameter equal to zero: x = 0. This reveals the exact point where the curve crosses the vertical axis line.
📈 INTERCEPT ANCHOR SCHEMATIC
STAGE 03: Determine Asymptotic Boundaries

Track infinite behaviors at extreme edges. An asymptote acts as an invisible boundary line that a curve approaches closer and closer but never actually touches or crosses:

Vertical Asymptotes (VA)
If limx → c± f(x) = ±∞

Found at isolated values x = c where the denominator equals zero, causing the function values to grow to infinity.

Horizontal Asymptotes (HA)
If limx → ±∞ f(x) = L

Found by calculating what happens to the graph at the far ends as x goes to infinity. The curve flattens to a horizontal level y = L.

STAGE 04: Compile a Variation Table

Calculate the first derivative f'(x) and second derivative f''(x) to check their signs across each domain interval. We collect all of this information into a single, unified variation table to show exactly where the curve is increasing, decreasing, turning at stationary points, or changing its concavity.

Worked Example: Complete Analysis of a Rational Function

  2. Axis Intercepts: Find where the curve crosses the axes on your coordinate grid layout:
    Horizontal (x-intercept):    2x = 0   ⇒   x = 0   ⇒   (0, 0)
    Vertical (y-intercept):    f(0) = 2(0)0 − 1 = 0   ⇒   (0, 0)
  3. Asymptotic Boundaries: Calculate the limits at the boundaries of the domain to check for asymptotes:
    Vertical (VA):    limx→1− f(x) = −∞,    limx→1+ f(x) = +∞   ⇒   x = 1
    Horizontal (HA):    limx→±∞ 2 1 − 1x = 2   ⇒   y = 2
