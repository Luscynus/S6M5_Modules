🛑 System Collapse: The 0÷0 Trap!

At the exact instant t = 1.00s, the tracking window completely vanishes. The change in time becomes zero (Δt = 0). Algebraically, our division formula yields 0 ÷ 0, which is a critical undefined error. Basic algebra is fundamentally broken at a single point because a single point has zero change!

Bypassing the Wall: The Limit Definition

On Slide 1, our interval gap was calculated as b - a (or t - 1). When the gap shrunk to absolute zero, the math broke down completely because we cannot divide by zero.

To bypass this wall, mathematicians re-imagined the interval gap as a standalone tiny placeholder variable called h (where h = b - a). Therefore, instead of tracking a separate point b, we define our second point position as c + h.

This subtle notation shift is incredibly powerful: as our two points collide, we simply evaluate the limit as the spacer distance h → 0:

🧮 The Limit Definition of the Derivative:
f'(c) = lim f(c + h) - f(c)h
📋 Bypassing the 0÷0 Crash with Algebra:

Let's apply this definition to our skier from Slide 1 (f(t) = t²) at our fixed anchor point (c = 1). Watch how the vanishing gap variable h cancels out completely to eliminate the division-by-zero error:

1. Set Up:
f'(1) = lim f(1 + h) - f(1)h = lim (1 + h)² - (1)²h
2. Expand:
= lim 1 + 2h + h² - 1h = lim 2h + h²h
3. Cancel & Solve:
= lim h(2 + h)h = lim(2 + h) = 2.00 m/s

📉 LIMIT ENGINE: CONVERGENCE TO TANGENT

Constructing the Tangent Line Equation

The derivative value f'(c) provides the exact instantaneous slope at a single point target. To map this line across space, we anchor this slope directly into the classic algebraic point-slope straight line formula framework:

📐 The Canonical Point-Slope Model:
y - f(c) = f'(c) · (x - c)

Where (c, f(c)) is the coordinate point and f'(c) is the slope (m).

Example 4.1 (Derivative at a Point):

Use the formal Limit Definition of the Derivative to calculate the exact instantaneous value of f'(3) for the base quadratic curve function f(x) = x².

Solution Method:
  1. Set Up the Limit Formula: We substitute our given coordinate target position c = 3 directly into the structural limit definition mapping:
    f'(3) = lim f(3 + h) − f(3)h
    We evaluate our individual function output landmarks using our rule f(x) = x²:
    f(3) = (3)² = 9          and          f(3 + h) = (3 + h)² = 9 + 6h + h²
  2. Expand and Simplify the Numerator: We substitute these resolved polynomial segments back into our fraction boundary and combine terms on top:
    f'(3) = lim (9 + 6h + h²) − 9h = lim 6h + h²h
  3. Simplify the Fraction and Evaluate the Limit: Directly substituting h = 0 triggers an indeterminate matrix collapse (0 ⁄ 0). We isolate h as a common scale factor to clear the zero gap:
    f'(3) = lim h · (6 + h)h = lim(6 + h)
    Evaluating the remaining limit path as spacer width h → 0 delivers our final slope value: f'(3) = 6 + 0 = 6.
Example 4.2 (Constructing a Tangent Equation):

Find the complete geometric line equation of the Tangent Line tracking along the curve f(x) = x² at the exact point boundary where x = 3.

Solution Method:
  1. Find the Coordinates of the Point and the Slope: We collect our prerequisite parameters at our target anchor position c = 3:
    • The vertical alignment y-coordinate: f(3) = 3² = 9
    • The target linear slope value (calculated in Example 4.1): f'(3) = 6
  2. Substitute the Values into the Formula: We anchor these properties into the classic point-slope equation structure:
    y − 9 = 6 · (x − 3)
  3. Simplify Into Standard Form: We expand the multiplier brackets and isolate our functional variable dependent coordinate y:
    y − 9 = 6x − 18
    y = 6x − 18 + 9      ⇒      y = 6x − 9
