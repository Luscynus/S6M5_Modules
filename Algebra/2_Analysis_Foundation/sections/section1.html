1. Introduction to Functions, Domain & Range

Foundations of Functions

A function f is a mathematical rule or machine. It takes a horizontal input value x from a starting boundary set called the Domain (Df), and maps it to exactly one unique vertical tracking position y inside an output set called the Range (Rf).

📐 GRAPHICAL MATRIX DIAGRAM: TRACKING BOUNDARIES
💡 Moving left-to-right measures the Domain span. Moving bottom-to-top measures the Range height span.
Standard Function Families & Their Spans:
  • Linear Functions: f(x) = mx + p

    Forms an infinite straight line. It has no boundaries or breaks: Df = ℝ and Rf = ℝ.

  • Quadratic Functions: f(x) = ax2 + bx + c

    Forms a curved parabola stretching infinitely left and right (Df = ℝ), but has a strict vertical turning peak called the Vertex at xvertex = -b2a.

    • If a > 0 (opens up), the vertex is a minimum: Rf = [yvertex, +∞ ).
    • If a < 0 (opens down), the vertex is a maximum: Rf = (-∞, yvertex ].
  • The Reciprocal Function: f(x) = 1x

    Forms a split hyperbola curve. It contains an absolute horizontal and vertical gap break at the origin where the denominators blow up to infinity: Df = ℝ \ {0} and Rf = ℝ \ {0}.

Finding Domain Constraints

When a function is defined using real numbers, we find its domain by applying three main structural constraints systematically:

⚙️ Essential Domain Restriction Principles

To determine the valid real-number input values for any algebraic combination, verify that all three mathematical structures are satisfied simultaneously:

  • 1. Denominator Bounds:

    The denominator of an algebraic fraction can never equal zero.

    1g(x)  ⇒  g(x) ≠ 0
  • 2. Even Radical Core:

    The expression nested inside a square root radical layer must be greater than or equal to zero.

    √g(x)  ⇒  g(x) ≥ 0
  • 3. Logarithmic Arguments:

    The value entering a natural or base log system must remain strictly positive.

    ln(g(x)) or log(g(x))  ⇒  g(x) > 0

Demonstration Masterclass

Example 1.1: Find the domain Df for the given fraction function:
f(x) = √x + 42x − 6
Solution Steps:
  1. Apply the square root constraint rule on the top numerator: To make sure the answer is a real number, the expression inside must be non-negative:
    x + 4 ≥ 0 ⇒ x ≥ −4
  2. Apply the denominator constraint rule on the bottom: The denominator cannot be equal to zero. To avoid dividing by zero, we isolate the restricted point value:
    2x − 6 ≠ 0 ⇒ 2x ≠ 6 ⇒ x ≠ 3
  3. Combine both boundaries into a single unified range: We combine both inequalities into a single interval with a gap at the number 3:
    Df = [−4, 3) ∪ (3, +∞)

Example 1.2: A quadratic function is given by the formula f(x) = x² − 6x + 5. Find the coordinates of its vertex and determine its range Rf.
Solution Steps:
  1. Find the x-coordinate of the vertex using the axis formula: We identify coefficients as $a=1, b=-6$. Because $a > 0$, the parabola opens upwards to a terminal minimum:
    xvertex = −b2a = −−62(1) = 3
  2. Substitute x = 3 back into the parent formula to find the absolute minimum height:
    f(3) = (3)² − 6(3) + 5 = 9 − 18 + 5 = −4
  3. State final boundary interval: Because the parabola opens upwards from its lowest terminal minimum point, our range interval is:
    Rf = [−4, +∞)
