6. Derivative Function and Rules

Rules & Reference Library

Instead of relying on limits every time, we use verified shortcuts to differentiate algebraic terms instantly. Master these core mechanics and reference matrices to solve complex expressions.

🔢 The Power Rule
f(x) = xn  ⇒  f'(x) = n · xn−1

Bring the exponent out to the front as a multiplier, then decrease the original power by exactly 1.

➕ Multipliers & Sums
[k · f(x)]' = k · f'(x)
[f(x) + g(x)]' = f'(x) + g'(x)

Derivatives pass smoothly through addition blocks and leave constant front multipliers attached.

⚠️ Remark: The Constant Zero Trap

A standalone constant term (like +5 or -12) represents a perfectly horizontal flat line with a slope of zero. Therefore, its derivative is exactly 0 and it vanishes from your calculation: f(x) = c ⇒ f'(x) = 0. Don't make the mistake of leaving it in!

📐 Algebraic Transformation Step

Before running the power rule on radicals or variables trapped in denominators, you must rewrite them into standard exponent blocks using exponent laws:

Fractions 1xn = x−n
Square Roots √x = x1/2
General Radicals n√xm = xm/n

Worked Examples

Study how the Power Rule handles front multipliers, polynomial sums, and radical conversions, then test your understanding in the interactive testing playground below.

Example 6.1 (Polynomial Differentiation):

Find the derivative function f'(x) for the multi-term polynomial curve:

f(x) = 2x³ − 5x² + 4x − 9
Solution:
  1. Differentiate each term: We apply the power rule term-by-term across each variable component:
    2(3x²) − 5(2x) + 4(1) − 0
  2. Simplify multipliers: Multiply out the constant coefficients to prepare the final expression:
    6x² − 10x + 4
  3. State the final derivative: The standalone constant term equals zero in our derivative calculations, giving our final equation:
    f'(x) = 6x² − 10x + 4
Example 6.2 (Reciprocal Radical Conversion):

Differentiate the expression by rewriting the radical term out of the denominator:

f(x) = 4√x
Solution:
  1. Rewrite with a negative fractional power: Turn the root denominator into a manageable component line using standard exponent rules:
    f(x) = 4x-1/2
  2. Apply the Power Rule: Bring the exponent down to the front as a multiplier and subtract exactly one from the exponent power value:
    f'(x) = 4 · (-1/2)x-3/2
  3. Simplify numerical factors: Simplify the front multiplier coefficient to state the final result:
    f'(x) = −2x-3/2
Example 6.3 (Mixed Identity Reference Lookup):

Find the derivative function f'(x) using the derivative reference table formulas for non-polynomial terms:

f(x) = 3ex + 5sin(x)
Solution:
  1. Look up the reference terms: Find the standard derivative rules directly from your common formulas table:
    [ex]' = ex          and          [sin(x)]' = cos(x)
  2. Apply constant multipliers: Keep the leading coefficients attached to each term during the differentiation step:
    3(ex) + 5(cos(x))
  3. State the final result: Combine these separate parts back into a single clean derivative equation:
    f'(x) = 3ex + 5cos(x)
