8. The Chain Rule

An Introduction to the Chain Rule

When finding the rate of change for nested functions, you cannot find the overall derivative by simply differentiating the parts independently. Think of it like a chain reaction: changing the inside variable shifts the inner layer, which then forces the outer function to change as well.

💡 The Outside-In Mental Model:

Think of a composite function like a wrapped gift. To find how fast the total system changes, you use a two-step process:
Step 1: Differentiate the Outside Wrapper (leaving the contents untouched).
Step 2: Multiply by the rate of change of the Inside Contents.

The Chain Rule Definition

If a composite function is defined as h(x) = f(g(x)), its derivative is found by multiplying the rate of change of the outer function by the rate of change of the inner function:

h'(x) = f'(g(x)) · g'(x)

🧮 Leibniz Notation Proof

Let y = f(u) and u = g(x). A small change in x forces a change in the inner expression u, which then causes a change in the final output y:

ΔyΔx = ΔyΔu · ΔuΔx

If we take the limit as the change in x approaches zero (Δx → 0), these small steps turn into exact derivatives:

dydx = dydu · dudx
🚨 The Composite Trap — Forgetting the Inner Part:

The derivative of a nested function is never equal to just the derivative of the outside layer on its own: [f(g(x))]' ≠ f'(g(x)). Forgetting to multiply by the inner derivative g'(x) is a very common error that will lead to completely incorrect tangent lines and answers.

Operational Formula Matrix

In practice, calculating derivatives using the abstract composite formula can take a lot of time. Instead, we use optimized shortcut patterns to handle standard algebraic expressions instantly.

🌍 THE UNIVERSAL NESTING PROTOCOL:

While the two patterns below are the most common algebraic expressions you will face, the Chain Rule works exactly the same for any nested function. Whether you have an algebraic expression inside a trigonometric function sin(g(x)), an exponential layer eg(x), or a logarithm ln(g(x)), you always differentiate from the outside-in: find the derivative of the outer function first, then multiply by the inner derivative g'(x).

📦 PROFILE A: POWERS OF BRACKETS

When an expression inside brackets is raised to a power:

[(g(x))n]' = n · (g(x))n-1 · g'(x)
  1. Bring the power exponent n to the very front.
  2. Decrease the bracket's power layer by exactly 1.
  3. Multiply everything by the internal derivative g'(x).
🧪 PROFILE B: RADICAL RADIX CORES

When a variable expression is nested underneath a classic square root sign:

√g(x)' = g'(x) 2√g(x)
  1. Compute the clean internal derivative g'(x).
  2. Drop that derivative directly into the numerator position.
  3. Set the denominator to exactly two times the original parent root.

Let the changes in our variables approach zero. We can evaluate these steps by multiplying our fraction by a matching fraction containing our middle variable, u:

ΔyΔx = ΔyΔu · ΔuΔx

Because the inner function layer g(x) is perfectly continuous, forcing the change in x to zero (Δx → 0) automatically forces the change in the middle variable u to zero as well (Δu → 0):

limΔx→0 ΔyΔx = (limΔu→0 ΔyΔu) · (limΔx→0 ΔuΔx)

These individual limits turn smoothly into standard derivative formulas, proving exactly why the derivative of the outer wrapper multiplies by the inner derivative part:

dydx = dydu · dudx

Chain Rule Examples

Take a look at how the Chain Rule works when it is combined with the product and quotient rules. Following these problems step-by-step will help you handle functions with multiple layers clearly.

Example 8.1 (Using the Product Rule and Chain Rule together):

Find the derivative of this function containing an expression inside a square root:

h(x) = x · √2x + 1
Solution:
  1. Separate into two parts: Let u(x) = x and v(x) = √2x + 1. Finding the derivative of the first part gives u'(x) = 1.
  2. Find the derivative of the square root part: For v(x), the inside function is g(x) = 2x + 1, which has a derivative of g'(x) = 2. Using our square root shortcut rule gives:
    v'(x) = 22√2x + 1 = 1√2x + 1
  3. Combine using the Product Rule formula: We put the parts together using the formula u'v + uv':
    h'(x) = (1) · √2x + 1 + x · 1√2x + 1
  4. Find a common denominator to add the terms: Multiply the first term by √2x + 1 / √2x + 1 to combine the fractions over a single bottom part:
    h'(x) = (2x + 1) + x√2x + 1
  5. Write down the final derivative: Add the like terms on top together to get your final answer formula:
    h'(x) = 3x + 1√ 2x + 1
Example 8.2 (Using the Quotient Rule and Chain Rule together):

Find the derivative of this fraction containing brackets raised to a power in the denominator:

h(x) = x(3x - 2)2
Solution:
  1. Identify the top and bottom parts: Let the top expression be u(x) = x → u'(x) = 1, and let the bottom expression be v(x) = (3x - 2)2.
  2. Find the derivative of the bottom part using the Chain Rule: Differentiate v(x) by bringing the power to the front and multiplying by the derivative of the expression inside the brackets:
    v'(x) = 2(3x - 2)1 · (3) = 6(3x - 2)
  3. Substitute the parts into the Quotient Rule formula: Place our expressions directly into the standard template u'v - uv'v2:
    h'(x) = (1) · (3x - 2)2 - x · [6(3x - 2)][ (3x - 2)2 ]2
  4. Factor out shared terms to simplify: Pull out the common term (3x - 2) from the top expression so it can cancel out cleanly with the bottom part:
    h'(x) = (3x - 2) · [ (3x - 2) - 6x ](3x - 2)4 = (3x - 2) - 6x(3x - 2)3
  5. Write down the final derivative: Combine the terms on top to find the fully simplified final formula:
    h'(x) = -3x - 2(3x - 2)3
