9. Stationary Points Analysis and Second Derivative

First Derivative Master Mapping

Calculus allows us to use derivative functions as sensors to trace the exact terrain profile of a curve without plotting hundreds of points manually.

First Derivative Mapping Principles

Use the sign changes and critical values of the first derivative to systematically chart the movement of the function:

📈 Increasing Intervals:
f'(x) > 0 ⇒ f(x) is increasing.
📉 Decreasing Intervals:
f'(x) < 0 ⇒ f(x) is decreasing.
Fermat's Theorem & The First Derivative Test

To locate and classify local extrema, first establish critical stationary coordinates where the tangent line flattens completely horizontal:

f'(x0) = 0

Once a stationary point is located, classify its geometric identity by tracking the directional slope transitions as inputs pass through the coordinate:

⛰️ Local Maximum (Peak)

The derivative flips from positive to negative: (+) → (0) → (−)

🕳️ Local Minimum (Valley)

The derivative flips from negative to positive: (−) → (0) → (+)

⚠️ The One-Way Directional Trap (Stationary Inflection

Finding f'(x) = 0 does not mean a turning point is guaranteed. Look at f(x) = x3. Its derivative f'(x) = 3x2 equals 0 at the origin. But because squaring any number yields a positive result, the slope is positive before *and* after zero. It forms a temporary flat plateau, not a turning crest.

The Second Derivative & Curvature Test

Instead of mapping neighbor points on a sign chart, you can look directly at how a curve bends. Differentiating a second time yields f''(x), which detects structural curvature instantly using the Smile/Frown Law.

📈 Concave Upward: The Smile 😃
f''(x) > 0

Positive acceleration values force the function to curve upward. When a stationary point is locked inside a smile, it forms a Local Minimum 🕳️.

📉 Concave Downward: The Frown 🙁
f''(x) < 0

Negative acceleration values force the function to curve downward. When a stationary point is locked inside a frown, it forms a Local Maximum ⛰️.

⚠️ The Inconclusive Flat Line Treap

If your second derivative evaluation returns f''(x0) = 0, the curvature at that point is perfectly flat. This test fails and tells you nothing! You must return to Slide 1's Neighbor Sign Test to find out what the curve is doing.

Example 9.1 (Extrema Hunting Loop):

Find and classify all local turning points (maximums and minimums) for the given cubic function:

f(x) = 13x3 + 3x2 + 8x − 6
Solution Method:
  1. Compute the Derivative Function: Apply standard power rules to isolate critical roots:
    f'(x) = x2 + 6x + 8
  2. Isolate Stationary Roots: Set the quadratic derivative to zero and solve via factoring:
    x2 + 6x + 8 = 0 ⇒ (x + 4)(x + 2) = 0 ⇒ x = −4, x = −2
  3. Construct Sign Variation Chart:
    x −∞ −4 −3 −2 +∞
    f'(x) + 0 − 0 +
    f(x) ↗ ⛰️ Max
    -34/3    		 ↘ 🕳️ Min
    -38/3    		 ↗
  4. Process Coordinates: Substitute the critical factors back into the raw function f(x) to secure exact coordinates:
    f(−4) = (−4)33 + 3(−4)2 + 8(−4) − 6 = −34/3
    f(−2) = (−2)33 + 3(−2)2 + 8(−2) − 6 = −38/3
  5. State Final Extrema Vectors: Gather the coordinates to state the terminal resolution points:
    Max = (−4, − 343 ),    Min = (−2, − 383 )
Example 9.2 (Inflection Landmark Explorer):

Find the intervals of curvature concavity and determine the exact coordinates of any inflection points for the function:

f(x) = x3 − 6x2 + 9x − 10
Solution Method:
  1. Run Consecutive Derivatives: Differentiate twice to isolate acceleration vectors:
    f'(x) = 3x2 − 12x + 9   ⇒   f''(x) = 6x − 12
  2. Isolate Inflection Boundaries: Find where the curvature shifts by evaluating the terminal root condition f''(x) = 0:
    6x − 12 = 0   ⇒   6x = 12   ⇒   x = 2
  3. Map the Curvature Signs: Evaluate boundary neighborhoods on either side of our candidate point:
    • For x < 2: f''(x) < 0 → Concave Curve 🙁 (Frown Profile)
    • For x > 2: f''(x) > 0 → Convex Curve 😃 (Smile Profile)
  4. Calculate Landmark Position: Plug the verified inflection variable root back into the raw function expression to extract the concrete spatial mapping:
    f(2) = (2)3 − 6(2)2 + 9(2) − 10 = 8 − 24 + 18 − 10 = −8
  5. State Final Inversion Vector: State the coordinate parameters where the geometric path profile alters orientation smoothly:
    (2, −8)
