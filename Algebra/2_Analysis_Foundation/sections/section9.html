9. Stationary Points Analysis and Second Derivative

Using the First Derivative to Map Graphs

Calculus allows us to use derivative functions to determine the exact shape of a curve without needing to plot hundreds of points manually.

How the First Derivative Directs the Graph

We can look at the sign changes and key values of the first derivative to see exactly how the graph moves up and down:

📈 Increasing Intervals:
f'(x) > 0 ⇒ f(x) is increasing.
📉 Decreasing Intervals:
f'(x) < 0 ⇒ f(x) is decreasing.
Finding and Classifying Turning Points

To find local maximums and minimums, we first look for stationary points where the tangent line becomes completely flat:

f'(x0) = 0

Once you locate a stationary point, you can determine its shape by checking how the derivative changes signs as you pass through that point:

⛰️ Local Maximum (Peak)

The derivative shifts from positive to negative: (+) → (0) → (−)

🕳️ Local Minimum (Valley)

The derivative shifts from negative to positive: (−) → (0) → (+)

⚠️ The Flat Plateau Trap (Stationary Inflection Point)

Finding f'(x) = 0 does not always guarantee a peak or a valley. Look at f(x) = x3. Its derivative f'(x) = 3x2 equals 0 at the origin. But because squaring any number always yields a positive result, the slope is positive both before and after zero. It forms a temporary flat plateau, not a turning point.

The Second Derivative and Concavity Test

Instead of mapping multiple test numbers on a first derivative sign chart, we can look directly at how a curve bends. Differentiating a second time gives us the second derivative function f''(x), which allows us to determine the concavity of the curve instantly using the Smile/Frown Analogy:

📈 Concave Upward: The Smile 😃
f''(x) > 0

When the second derivative is positive, the function is concave up. If a stationary point occurs where a curve forms a smile, that point forms a valid Local Minimum 🕳️.

📉 Concave Downward: The Frown 🙁
f''(x) < 0

When the second derivative is negative, the function is concave down. If a stationary point occurs where a curve forms a frown, that point forms a valid Local Maximum ⛰️.

⚠️ The Inconclusive Second Derivative Exception

If your second derivative evaluation returns f''(x0) = 0, the curvature at that coordinate is perfectly flat. This means the Second Derivative Test fails and provides no information! To determine the behavior of the curve at this point, you must return to Slide 1's first derivative Neighbor Sign Test.

Example 9.1 (Finding and Classifying Turning Points):

Find and classify all local turning points (local maximums and local minimums) for the given cubic function:

f(x) = 13x3 + 3x2 + 8x − 6
Solution Steps:
  1. Find the derivative function: Apply the power rule to calculate the first derivative:
    f'(x) = x2 + 6x + 8
  2. Find the stationary points: Set the derivative equal to zero and solve the equation by factoring:
    x2 + 6x + 8 = 0 ⇒ (x + 4)(x + 2) = 0 ⇒ x = −4, x = −2
  3. Construct the derivative sign chart:
    x −∞ −4 −3 −2 +∞
    f'(x) + 0 − 0 +
    f(x) ↗ ⛰️ Max
    -34/3    		 ↘ 🕳️ Min
    -38/3    		 ↗
  4. Calculate the y-coordinates: Substitute the stationary x-values back into the original function f(x) to find the exact coordinates:
    f(−4) = (−4)33 + 3(−4)2 + 8(−4) − 6 = −34/3
    f(−2) = (−2)33 + 3(−2)2 + 8(−2) − 6 = −38/3
  5. State the turning points: List the final localized maximum and minimum point coordinates:
    Local Max = (−4, − 343 ),    Local Min = (−2, − 383 )
Example 9.2 (Finding Inflection Points and Concavity Intervals):

Find the intervals of concavity and determine the exact coordinates of any inflection points for the function:

f(x) = x3 − 6x2 + 9x − 10
Solution Steps:
  1. Find the first and second derivatives: Differentiate the function twice in a row to find the second derivative function f''(x):
    f'(x) = 3x2 − 12x + 9   ⇒   f''(x) = 6x − 12
  2. Find where the second derivative equals zero: Set up the inflection point condition by solving the equation f''(x) = 0:
    6x − 12 = 0   ⇒   6x = 12   ⇒   x = 2
  3. Determine the concavity intervals: Check the sign of the second derivative on either side of our candidate point x = 2 to track how the curve bends:
    • For x < 2: f''(x) < 0 → The curve is concave down 🙁 (Frown Profile)
    • For x > 2: f''(x) > 0 → The curve is concave up 😃 (Smile Profile)
  4. Calculate the y-coordinate: Substitute the verified x-value back into the original function expression to find the exact position of the inflection point:
    f(2) = (2)3 − 6(2)2 + 9(2) − 10 = 8 − 24 + 18 − 10 = −8
  5. State the inflection point: Write down the final coordinates where the curve smoothly shifts its concavity:
    (2, −8)
